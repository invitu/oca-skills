# Evidence

Review comments behind the rules of this pack, collected in November 2026
from about 6,000 review comments (inline, conversation and review bodies) in
l10n-germany, bank-statement-import, bank-payment, account-reconcile,
account-financial-tools, account-invoicing, account-financial-reporting,
server-tools, server-ux, server-backend, web, partner-contact, social,
reporting-engine, l10n-netherlands, l10n-spain and maintainer-tools, plus the
OCA threads since 2025 where core reviewers discuss AI-assisted contributions.
Each rule was asked for in several pull requests; one example is linked per
quote. Attribution is to the pull request, not to the person.

Key threads on AI-assisted contributions: OCA/bank-statement-import#965 (AI
reviews), OCA/web#3732 (reviewed AI-assisted work is accepted),
OCA/server-backend#431 (removal pass), OCA/bank-statement-import#1025 and
OCA/helpdesk#1089 (generated tests).
