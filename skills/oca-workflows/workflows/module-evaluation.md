# Evaluation of a third-party module

Before adopting an existing module.

**Input**: the module and its repository.

| # | Step | Reads | Writes | Notes |
|---|---|---|---|---|
| 1 | evaluation (role to write) | repository, manifest, code, issues | `evaluation_*.md` | series available, license, dependencies, tests present, recent activity, open issues; each fact with its source, the rest "TO CONFIRM" |
| 2 | human | the evaluation | decision | adopt, adapt, or write another module |
